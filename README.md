# 🌫️ Image Haze Transformation Tool

Transform your images with forensic-grade haze effects, pixel shifts, and confidence-based heatmaps. Designed for clarity, reproducibility, and visual insight. showing how by only knowing the order and type of trasnformation applied on the page we can reproduce the image even from totatly looking random image.

---

## 🔧 Features

- **Upload & Preview**: Drag and drop any image to begin transformation.
- **Transformation Options**:
  - Haze
  - Pixel Shift
  - Invert
  - Grayscale
  - Sepia
  - Blur
  - Brightness / Contrast
  - Gaussian Blur
- **Confidence Heatmap**:
  - Red: Low Confidence
  - Yellow: Medium Confidence
  - Green: High Confidence
  - Black: Unchanged

---

## 🖼️ Interface Overview

| Panel | Description |
|-------|-------------|
| **Original Image** | Displays the uploaded image |
| **Transformed Image** | Shows the result after applying selected effects |
| **Pixel Difference** | Highlights changes between original and transformed |
| **Heatmap** | Visualizes confidence levels across the image |

---

## 🎛️ Controls

- **Brightness / Contrast**: Fine-tune image clarity
- **Haze Opacity**: Adjust mist intensity
- **Pixel Shift Range**: Set displacement range
- **Gaussian Blur Radius**: Smooth image edges
- **Diff Threshold**: Filter pixel changes by intensity

---

## 💾 Save & Reset

- **Save Image**: Export the transformed result
- **Reset**: Clear all transformations and start fresh

---
